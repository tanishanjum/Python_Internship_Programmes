<section id="overview">
  <div class="content-box">
    <h2>Project Overview</h2>
    <p>This project addresses the critical problem of undetected underground water leakages, which lead to resource waste and infrastructure damage. It uses multiple sensors (flow, pressure, moisture, vibration) integrated with an ESP32 microcontroller. The system provides real-time monitoring and sends alerts via Wi-Fi to notify users of any detected leakages.</p>
  </div>
</section>

<section id="components">
  <div class="content-box">
    <h2>Hardware Components</h2>
    <ul>
      <li>ESP32 Core Microcontroller</li>
      <li>YF-S201 Water Flow Sensor</li>
      <li>BMP280 Pressure Sensor</li>
      <li>Capacitive Soil Moisture Sensor</li>
      <li>SW-420 Vibration Sensor</li>
      <li>Mini Submersible Water Pump (Testing)</li>
      <li>Relay Module, Buzzer, LEDs (Alerts)</li>
      <li>Wi-Fi for Alert Transmission</li>
      <li>Battery Pack and Enclosure Box</li>
    </ul>
  </div>
</section>

<section id="working">
  <div class="content-box">
    <h2>Working Principle</h2>
    <p>The system constantly collects data from the sensors and analyzes it using threshold logic on the ESP32. If any anomaly indicating a potential leak is detected, it triggers a local buzzer/LED and sends a remote alert via Wi-Fi. This enables early detection and quick response, minimizing water loss and system damage.</p>
  </div>
</section>
